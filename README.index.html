Tipos de Datos en Bases de Datos

Guía esencial de estructuras de almacenamiento en sistemas gestores de bases de datos (SGBD)

¿Qué son los tipos de datos?

En una base de datos relacional, cada columna de una tabla requiere un tipo de dato definido. Este tipo de dato actúa como una restricción que asegura la integridad de la información, determinando qué valores se pueden almacenar (números, textos, fechas, etc.) y optimizando el espacio de almacenamiento.

Tipos de Datos Principales

Tipo de Dato Categoría Descripción Ejemplos de Valores
INT Numérico Entero Almacena números enteros sin parte decimal, tanto positivos como negativos. 10, -450, 2026
VARCHAR(n) Cadena de Caracteres Texto de longitud variable hasta un límite máximo especificado (n). Eficiente en espacio. 'Alejandro', 'contacto@email.com'
DECIMAL / NUMERIC Numérico Exacto Números con precisión fija y parte fraccionaria. Indispensable para valores monetarios. 99.99, 15000.50
DATE / DATETIME Fecha y Hora Almacena fechas del calendario o combinaciones precisas de fecha y hora exacta. 2026-06-07, 2026-06-07 15:30:00
BOOLEAN Lógico Maneja valores de verdadero o falso. Dependiendo del motor, puede representarse como 1/0. TRUE, FALSE
TEXT Texto Largo Diseñado para almacenar cadenas de texto de gran tamaño, como artículos o descripciones extensas. Contenido de publicaciones de un blog, comentarios largos.
